# Manyoha Plumbing Services

## 1. Project Overview

Manyoha Plumbing Services is a website developed to provide information about a plumbing business and the services it offers. The website allows visitors to learn about the business, explore its plumbing services, and make enquiries.

The website is designed with a simple and professional layout that is easy to navigate.

## 2. Project Objectives

The objectives of this project are to:

- Create a professional website for Manyoha Plumbing Services.
- Provide information about the business and its services.
- Allow customers to make plumbing service enquiries.
- Make business contact information easy to find.
- Use HTML to structure the website content.
- Use CSS to improve the website's appearance.
- Create a website that is easy to navigate.

## 3. Website Pages

The website consists of the following pages:

- **Home:** Introduces the business and highlights its main services.
- **About Us:** Provides information about the business.
- **Services:** Describes the plumbing services offered.
- **Enquiry:** Allows customers to enquire about plumbing services.
- **Contact Us:** Provides information about contacting the business.

## 4. Technologies Used

The following technologies and tools were used to develop the website:

- **HTML5:** Used to structure the website content.
- **CSS3:** Used to style the website, including colours, fonts, spacing, and layout.
- **GitHub:** Used to store and manage the website's source code.
- **GitHub Pages:** Used to publish the website online.

## 5. Website Design

The website uses a blue and white colour scheme to create a professional appearance suitable for a plumbing business.

The design includes:

- A light blue background.
- Blue headings.
- Readable fonts and font sizes.
- Navigation links between website pages.
- Relevant plumbing images.
- Consistent styling throughout the website.

## 6. Website Features

The main features of the website include:

- A homepage introducing Manyoha Plumbing Services.
- Information about the business.
- A page describing the plumbing services.
- An enquiry page.
- A contact page.
- Navigation links that help visitors move between pages.
- CSS styling to improve the appearance of the website.
